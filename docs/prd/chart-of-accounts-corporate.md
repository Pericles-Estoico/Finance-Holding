## FÓRMULAS AUTOMÁTICAS PARA CÁLCULO

### DRE - Demonstração do Resultado do Exercício

```
RECEITA OPERACIONAL BRUTA
= Vendas Produtos (4.1.1) + Vendas Serviços (4.1.2) + Outras Receitas Operacionais (4.1.3)

(-) DEDUÇÕES DA RECEITA
= Devoluções (4.2.1) + Descontos (4.2.2) + Abatimentos (4.2.3) + Impostos sobre Vendas (4.2.4)

= RECEITA OPERACIONAL LÍQUIDA

(-) CUSTO DOS PRODUTOS VENDIDOS (CPV)
= Matéria-Prima (5.1.1) + Mão de Obra Direta (5.1.2) + Custos Indiretos (5.1.3) 
  + Embalagem (5.1.4) + Logística de Entrada (5.1.5) + Variação de Estoque (5.1.6)

= LUCRO BRUTO

(-) DESPESAS OPERACIONAIS
= Despesas Comerciais (5.3.1) + Despesas Administrativas (5.3.2) + Despesas Financeiras (5.3.3)

= LUCRO OPERACIONAL (EBIT)

(+) EBITIDA
= EBIT + Depreciação (5.3.2.5.1-5.3.2.5.3) + Amortização (5.3.2.5.4-5.3.2.5.6)

(-) DESPESAS NÃO OPERACIONAIS
= Despesas Não Operacionais (5.6.1) + Provisões (5.6.2)

= LUCRO ANTES DOS IMPOSTOS

(-) IMPOSTOS SOBRE O LUCRO
= IRPJ (5.8.1.1) + CSLL (5.8.2.1)

= LUCRO LÍQUIDO
```

### INDICADORES PARA INVESTIDORES

```
MARGEM BRUTA = (Lucro Bruto / Receita Operacional Líquida) × 100
MARGEM OPERACIONAL = (EBIT / Receita Operacional Líquida) × 100
MARGEM EBITIDA = (EBITIDA / Receita Operacional Líquida) × 100
MARGEM LÍQUIDA = (Lucro Líquido / Receita Operacional Líquida) × 100

RETORNO SOBRE PATRIMÔNIO (ROE) = (Lucro Líquido / Patrimônio Líquido) × 100
RETORNO SOBRE ATIVOS (ROA) = (Lucro Líquido / Ativo Total) × 100

EBITIDA / Receita = Indicador de Saúde Operacional (Ideal: > 20% para varejo)
```

## FLUXO DE CAIXA (Derivado da DRE)

```
FLUXO OPERACIONAL
= Lucro Líquido 
  (+) Depreciação e Amortização
  (+/-) Variação de Contas a Receber
  (+/-) Variação de Estoques
  (+/-) Variação de Contas a Pagar
  = FLUXO DE CAIXA OPERACIONAL

FLUXO DE INVESTIMENTO
= (-) Compra de Ativo Fixo
  (-) Compra de Investimentos
  (+) Venda de Ativo Fixo
  = FLUXO DE CAIXA DE INVESTIMENTO

FLUXO DE FINANCIAMENTO
= (+) Empréstimos Recebidos
  (-) Pagamento de Empréstimos
  (+) Aumento de Capital
  (-) Dividendos Pagos
  = FLUXO DE CAIXA DE FINANCIAMENTO

VARIAÇÃO LÍQUIDA DE CAIXA
= Fluxo Operacional + Fluxo de Investimento + Fluxo de Financiamento

CAIXA FINAL = Caixa Inicial + Variação Líquida de Caixa
```

## NOTAS IMPORTANTES PARA IMPLEMENTAÇÃO

1. **Precisão Numérica**: Usar `decimal.js` para evitar erros de ponto flutuante
2. **Auditoria**: Cada transação deve ser rastreável até o comprovante original
3. **Conformidade**: Estrutura alinhada com IFRS 15 (Receita), IFRS 16 (Leasing), IFRS 9 (Instrumentos Financeiros)
4. **Drill-Down**: Sistema deve permitir clicar em qualquer linha e ver transações subjacentes
5. **Comparativos**: Sempre mostrar período anterior e benchmark do setor
6. **Alertas**: Sinalizar automaticamente desvios > 10% do orçado
7. **Auditoria de Dados**: Manter log de todas as alterações (quem, quando, o quê)
