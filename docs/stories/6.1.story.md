# Story 6.1 — Plano de Contas Gerencial Simplificado (DRE-aligned)

**Status:** InProgress
**Epic:** 6 — Plano de Contas Unificado
**Agent:** @dev (Dex)

## Problem

O sistema tinha dois planos de contas paralelos (legado + V2 corporativo com 80+ contas
genéricas) que forçavam o usuário a classificar o mesmo lançamento duas vezes. O plano V2
tinha contas de ASSET/LIABILITY/EQUITY que não mapeavam ao DRE, causando R$0 nas dashboards.

## Solution

Substituir chart_accounts_v2 por plano gerencial específico para fábrica de roupas/e-commerce
com 6 grupos que mapeiam diretamente às linhas do DRE via campo `account_type`.

## DRE Mapping

| Grupo | account_type | Linha DRE |
|-------|-------------|-----------|
| 1.1.x | receita | Receita Bruta |
| 1.2.x | deducao | (-) Deduções |
| 1.3.x | receita_nao_op | Receita Bruta (outras) |
| 2.x | cpv | (-) CMV |
| 3.x | despesa_operacional | (-) Despesas Operacionais |
| 4.x | despesa_financeira | (-) Despesas Financeiras |
| 5.x | investimento | Não entra no DRE |
| 6.x | nao_operacional | Não entra no DRE |
