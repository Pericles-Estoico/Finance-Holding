## Contexto

A interface de classificação manual de pendentes usa um `<select>` flat com as contas do plano legado. Precisa ser atualizada para usar o plano corporativo com hierarquia (AccountClass > Grupo > Conta), quando disponível.

---

## Valor de Negócio

O operador financeiro que classifica manualmente um lançamento pendente precisa ver a hierarquia do plano corporativo para classificar no nível correto — sem isso, os lançamentos vão para contas genéricas que não alimentam a DRE IFRS corretamente.

## Escopo

**IN:**
- Componente `CorporateAccountSelect.tsx` — combobox com hierarquia visual
- `ImportarPage.tsx` usa `CorporateAccountSelect` quando plano v2 disponível
- Seção de classificação de pendentes (Drive Import) também atualizada

**OUT:**
- NÃO remover o select legado (mantido como fallback)
- NÃO alterar a API de classificação (`classify.ts`)
