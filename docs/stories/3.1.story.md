## Contexto

O OCR atual sugere códigos do plano legado (ex: '3.4.1'). Com o Plano Corporativo v2 já implementado, o OCR precisa sugerir contas específicas com código e nome completo (ex: "3.1.1.1 Frete — Correios").

---

## Valor de Negócio

A classificação automática precisa usar o plano corporativo para que cada lançamento seja rastreável ao demonstrativo IFRS. Sem isso, o OCR gera lançamentos no plano legado que não alimentam a DRE corporativa.

## Escopo

**IN:**
- Função `suggestCorporateAccount(text, accounts)` em novo arquivo de serviço
- Atualização do `OcrParsed` com campo `suggestedCorporateAccountId`
- `ImportarPage.tsx` usa conta corporativa quando disponível
- Fallback para plano legado quando sem plano corporativo

**OUT:**
- NÃO alterar a API do Google Vision (continua igual)
- NÃO alterar tabela no banco
