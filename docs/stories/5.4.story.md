# Story 5.4 — Filtrar contas por tipo na classificação de comprovantes

**Status:** InProgress
**Epic:** 5 — Bug Fixes
**Agent:** @dev (Dex)

## Problem

Na tela de classificação (Drive e upload manual), o dropdown "Conta do plano" exibe
TODOS os tipos de conta (RECEITA, DESPESA, ATIVO, PASSIVO, PATRIMÔNIO) independente
do "Tipo" selecionado (Receita/Despesa). Isso permite — e até induzia — o usuário a
selecionar uma conta de ATIVO para uma transação do tipo "receita", fazendo com que
o lançamento fosse silenciosamente ignorado pelo `calcDRE`.

Segundo problema: no upload manual, `handleConfirm` chama `createTransaction` com
`account_id`, mesmo quando a conta selecionada é do plano Corporativo V2 — o campo
`chart_account_v2_id` nunca era setado, tornando o lançamento invisível para o DRE
com V2 accounts.

## Acceptance Criteria

- [ ] Tipo "Receita" → dropdown mostra apenas contas REVENUE
- [ ] Tipo "Despesa" → dropdown mostra apenas contas EXPENSE
- [ ] Trocar o Tipo reseta a conta selecionada (evita conta inválida ficar salva)
- [ ] Upload manual com conta V2 salva `chart_account_v2_id`, não `account_id`
- [ ] `TransactionPayload` aceita `account_id` ou `chart_account_v2_id` (ambos opcionais)
