## Contexto

O `financeCalculations.ts` atual faz cálculos básicos de DRE, mas sem a cadeia IFRS completa. Precisamos de um engine que calcule automaticamente toda a cascata:

```
Receita Bruta → (-) Deduções → Receita Líquida
Receita Líquida → (-) CPV → Lucro Bruto  
Lucro Bruto → (-) Despesas Operacionais → EBIT
EBIT → (+) D&A → EBITDA
EBIT → (-) Desp. Não Operacionais → (-) Impostos → Lucro Líquido
```

---

## Valor de Negócio

O engine IFRS é o coração do sistema. Sem ele, DRE, EBITDA e Lucro Líquido são calculados com lógica dispersa e JS nativo (sujeito a erros de ponto flutuante). Com ele, todos os relatórios de investidores dependem de um único serviço auditável e testado, o que é requisito para due diligence de M&A.

## Escopo

**IN:**
- Novo arquivo `ifrsEngine.ts` com toda a cadeia de cálculo IFRS
- `decimal.js` em todos os cálculos monetários
- Funções de KPI (Margem Bruta, EBITDA, ROE, ROA)
- Testes unitários mínimos (5 cenários)
- Integração no `DreScreen.tsx`

**OUT:**
- NÃO implementar UI nova (Story 1.3)
- NÃO implementar Balanço Patrimonial (Epic 4)
- NÃO calcular indicadores de investidores completos (Epic 2)
- NÃO tocar em `financeApi.ts` (apenas `financeCalculations.ts`)
