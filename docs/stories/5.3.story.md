# Story 5.3 — V2 Corporate Chart visibility in Dashboard, DRE and Reports

**Status:** Done
**Epic:** 5 — Bug Fixes
**Agent:** @dev (Dex)

## Problem

Transactions classified with Corporate Chart V2 accounts have `account_id = null` and
`chart_account_v2_id` set. The `calcDRE` function in `lib/dre.ts` looks up accounts by
`account_id` — `get(null)` → undefined → transaction silently skipped in all KPI calculations.

Affected pages: Dashboard, DRE, Relatorios (all use `transactions → calcDRE`).

## Acceptance Criteria

- [ ] Transactions with V2 accounts appear in Dashboard RECEITA BRUTA / KPIs
- [ ] DRE page shows V2 transactions in correct line
- [ ] Relatorios page includes V2 transactions
- [ ] `Transaction` type updated to include `chart_account_v2_id`
- [ ] `calcDRE` handles V2 accounts via `account_class` → DRE group mapping
  - `REVENUE` → receita bruta
  - `EXPENSE` → despesa operacional
