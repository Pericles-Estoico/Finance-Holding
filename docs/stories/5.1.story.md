# Story 5.1 — Fix Drive Import Deadlock (3 bugs)

**Status:** Done
**Epic:** 5 — Bug Fixes
**Agent:** @dev (Dex)

## Problem

Three chained bugs cause a permanent deadlock when classifying receipts imported from Google Drive using the Corporate Chart (Plano Corporativo V2):

1. **FK Violation:** `transactions.account_id` has FK → `chart_of_accounts`, but `CorporateAccountSelect` returns `chart_accounts_v2.id`. Insert fails silently.
2. **Stuck files:** `check-processed.ts` returns all statuses (including `pending`), so stuck files are skipped on re-scan forever.
3. **Hidden error:** `driveError` renders above the pending accordion — user never sees the failure message.

Secondary fix also needed in `process-file.ts` to clean up stuck `pending` records on re-scan.

## Acceptance Criteria

- [ ] Classifying a receipt with a V2 corporate account saves a transaction successfully
