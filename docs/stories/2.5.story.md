## Contexto

O `CashFlowScreen` já mostra o fluxo de caixa do período atual. Investidores de PE precisam ver a projeção de 3 a 5 anos com CAGR configurável — é a base do valuation pelo método do Fluxo de Caixa Descontado (DCF).

---

## Valor de Negócio

Uma projeção de fluxo de caixa 5 anos é requisito mínimo para qualquer processo M&A ou captação série A/B. Gerar isso automaticamente a partir dos dados reais (com CAGR ajustável) elimina semanas de trabalho de consultoria.

## Escopo

**IN:**
- Nova tela `CashFlowProjectionScreen.tsx` no carousel (8ª tela)
- Projeção de 3 ou 5 anos com CAGR de receita configurável
- Linha de EBITDA projetado (CAGR independente)
- Gráfico de barras (Recharts) mostrando evolução anual
- Tabela com valores anuais projetados

**OUT:**
- NÃO implementar DCF completo (taxa de desconto, VPL — escopo futuro)
- NÃO integrar com dados macro externos (IPCA, CDI)
- NÃO salvar projeções (estado local apenas)

## Riscos

| Risco | Probabilidade | Impacto | Mitigação |
|-------|--------------|---------|-----------|
| Receita base zero → projeção zerada | Média | Baixo | Aviso + fallback para mock |
