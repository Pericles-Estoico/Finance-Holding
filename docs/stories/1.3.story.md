# Story 1.3 — UI: Árvore Hierárquica do Plano de Contas Corporativo

**Epic:** EPIC-1 — Plano de Contas Corporativo IPO/M&A  
**Status:** Ready  
**Executor:** @dev  
**Quality Gate:** @architect  
**Complexidade:** L (8 pts) — componente complexo com árvore, CRUD e integração API  
**Branch:** `feat/chart-accounts-corporate-ui`  
**Dependência:** Story 1.1 (schema v2)  

---

## Contexto

O `ChartAccountsManager.tsx` atual gerencia o plano básico. Precisamos de uma UI que suporte a estrutura de 5 classes com até 5 níveis de hierarquia, mostrando saldos em tempo real e permitindo drill-down por conta.

---

## Valor de Negócio

O contador ou CFO precisa visualizar e gerenciar o plano de contas corporativo de forma intuitiva. Uma UI hierárquica com saldos em tempo real é o ponto de entrada para qualquer customização pós-seed e é o que diferencia o sistema de uma planilha.

## Escopo

**IN:**
- Componente `CorporateChartManager.tsx` com árvore expansível
- CRUD de contas (criar, editar nome/tipo, soft delete)
- Filtro por classe
- Botão de seed do template corporativo
- API service para `chart_accounts_v2`

**OUT:**
- NÃO implementar seed SQL (Story 1.4)
- NÃO mostrar saldos calculados (requer Story 1.2)
- NÃO implementar lançamentos multi-linha (escopo futuro)
- NÃO implementar mapeamento por canal nesta story

## Riscos

| Risco | Probabilidade | Impacto | Mitigação |
|-------|--------------|---------|-----------|
| Performance com árvore de ~200 contas | Média | Médio | Virtualização (react-window) ou lazy expand |
| Conflito de tab com `ChartAccountsManager` existente | Alta | Baixo | Separar tabs claramente: "Plano Básico" vs "Corporativo" |
| Usuário deletar conta pai com filhos | Média | Alto | Bloquear delete se tiver filhos ativos |

---

## Acceptance Criteria

- [ ] AC1: Componente `CorporateChartManager.tsx` com árvore expansível (accordion) mostrando as 5 classes
- [ ] AC2: Cada conta exibe: código, nome, saldo do período selecionado
- [ ] AC3: Contas calculadas (Receita Líquida, Lucro Bruto, EBIT, EBITDA, LL) destacadas visualmente (sem edição)

- [ ] AC6: Botão "Importar Template Corporativo" que dispara seed (se contas v2 estiverem vazias)
- [ ] AC7: Filtro por classe (Ativo / Passivo / PL / Receitas / Custos)
- [ ] AC8: Responsivo — funciona em tela cheia desktop
